# 🧠 Seminario de Actualización 2026 - Construcción de Proyecto Integrador

## 📋 Descripción del Proyecto

Este repositorio reúne el desarrollo de una aplicación basada en un modelo de Machine Learning, desde la preparación de datos hasta su puesta en línea como servicio accesible públicamente.

🎯 **Objetivo final:** contar con una aplicación web funcional que reciba entradas del usuario, ejecute el modelo entrenado y devuelva predicciones en tiempo real.

## ✅ Requisitos Previos

- Python 3.13 o superior
- Gestor de paquetes, preferentemente `pip`
- Git instalado y configurado

## 💻 Instalación y Uso Local

```bash
git clone https://github.com/sebsmedina/seminario_2026_proyecto_integrador
cd seminario_2026_proyecto_integrador
pip install -r requirements.txt
python app.py
